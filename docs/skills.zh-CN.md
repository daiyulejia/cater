# 按需工作指引

支持原生工具调用的伙伴会收到一页 `skills_index`：只含标识、用途、来源、版本及可用状态，不自动附上所有正文。伙伴根据任务选择 `read_skill`；更多目录用 `list_skills` 翻页。简单工作不需要先读指引。

内置五份短指引：问题溯源、工程运行与检查、静态网页检查、具体版本复核、面向顾客的交付讲解。只有当前实际工具满足前置条件时才提供对应条目。它们帮助角色核查调用链、实际结果和未验证范围，不替模型作出正确性保证，也不强制经过会议、投票或独立复核。

## 登记项目方法

宿主可以创建 UTF-8 JSON 清单，例如：

```json
{
  "skills": [
    {
      "id": "project-checks",
      "title": "项目运行与检查",
      "description": "记录该工程的构建入口、验证方法和已知限制。",
      "path": "F:/projects/example/SKILL.md",
      "roles": ["dev", "test"],
      "workspaces": ["example"],
      "requires": ["workspace_read"]
    }
  ]
}
```

将路径替换为本机已有的普通 `.md` 文件，角色及工作区标识以实际配置为准。启动时使用全局参数：

```powershell
python -m cater --skills F:/projects/example/skills.json web
```

Python 接口为 `Runtime(..., skills_path=...)`；Web 的 `serve`、`make_handler` 也接受该参数。采用自定义 `runtime_factory` 时，由工厂给 Runtime 传入配置，不会覆盖其设置。

- `id` 唯一，限 1 至 80 个英文字母、数字、下划线或连字符，不能覆盖内置条目。
- `title` 最多 160 字符，`description` 最多 400 字符；短用途有助于伙伴选择，而不是读取整个目录。
- `path` 必须是绝对路径。相对路径、受保护路径、链接/重解析点、硬链接、特殊文件及非 UTF-8 正文不读取。Windows 请使用完整路径，不使用 `~1` 一类短路径别名。
- `roles`、`workspaces` 省略表示不按该项筛选，空数组表示不给任何对象提供；`requires` 是实际工具名列表，全部可用才提供，空数组或省略表示无工具前置。
- 清单最多 128 项、1 MiB；每份 Markdown 最多 64 KiB。这里只读取 Markdown 正文，不解析 YAML 前言、不安装依赖、不发现或执行同目录脚本。

工具调用只接受登记的 `skill_id`，不能自行传文件路径、改变提供范围或新增登记。清单每次读取时重新核对；配置失效会停止提供自定义条目，不沿用旧缓存，内置指引和普通工作工具不因此停用。

## 版本与展示

`list_skills` 默认一页 5 项，最多 20 项。`read_skill` 默认每页 8000 字符，最多 12000 字符；返回原始文件字节的 SHA-256、正文总字符数和下一页起点。续读时传 `expected_sha256` 可以阻止跨版本拼接，版本变化会返回明确错误，需重新核对目录。

目录和正文读取留在现有可展开过程及审计中，正文默认再次折叠，只按纯文本展示，不执行其中 HTML、链接或命令。历史回执保留当时读过的版本，不随当前文件更新而改写。

## 权限边界

**指引是参考，不是工具权限、执行结果或验收证明。** 暂停时可只读查阅，不能借此恢复写入、命令、委托或交付权限。命令仍须通过实际工作区工具运行；已读指引不能作为真实执行证据引用。

提供范围用于相关性筛选，不是同群保密 ACL。已读正文会进入本群工具历史，后续可能由伙伴和操作者查看；撤销配置不会擦掉历史。不要在指引中放 API Key、凭据或不应向群内公开的内容。普通工作区命令仍在宿主权限下运行，这不是 OS 沙箱。

Skill 不等于 MCP 接入。当前另有可选的[本地 MCP stdio 工具](mcp.zh-CN.md)，仅连接宿主明确配置的服务，按需列工具和调用；不支持通用远程服务发现、HTTP/SSE、OAuth 或自动安装。详见[当前执行能力](capabilities.zh-CN.md)、[工程工作目录](workspaces.zh-CN.md)。
