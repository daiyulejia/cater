# 同项目历史背景

原生消息协作可按需读取同一项目中其他普通对话的历史交付。例如先在一个群交付接口模块，再在同项目的新群增加功能：伙伴可以找到当时的代码和说明，按新目标验证和修改，不必复制整个旧群聊天。

这是有来源的历史参考，不是自动记住所有聊天、模型内部长期记忆或已经确认的永久事实。

## 使用

1. 通过现有“店规”入口新建或选择项目，将相关普通对话关联到同一个项目。项目以稳定 ID 区分，同名不表示同一项目。
2. 在新群正常说明目标，例如“在之前交付的总数接口上增加平均数功能”。角色得到轻量历史索引，需要时才读取文件或交付说明。
3. 新群仍在自己绑定的工作目录操作，按新目标检查、复核并发布成果。历史文件不会因被读取而自动落盘、加入新交付或获得运行权限。

默认索引至多三条，每个来源群只列所选事件版本内最近的可信交付；只包含短目标、短摘要和少量文件引用。更多目录及完整文件引用按需读取，不强制所有角色阅读所有历史。

## 隔离与版本

- 只共享明确同项目、非隔离群的原生历史交付，不读取任意任务 ID、其他项目、未关联群或其他群的聊天、私有推理与角色最后一句发言。
- 未交付草稿、单纯发布记录和“我做好了”的聊天不会因此进入目录。目录里的店长交付结论仍是当时的声明，不是独立实测或当前正确性保证。
- “基于此对话开新任务”的衍生群继续只读取创建时的冻结背景，不加入实时项目目录；来源群后续修改不会偷偷同步进来。
- 文件读取来自指定交付引用的持久事件，核对来源群、文件名、序号及正文 SHA-256，不读取可能已经变化的当前磁盘文件。
- 后续页带同一 `as_of_seq` 保持历史版本。源群后来更换目标或交付新版，不改写旧版本的内容；新一次目录查询可以看到新交付。
- 旧上下文的项目范围发生变化时拒绝读取，不把角色旧请求用于另一项目。暂停下可以只读核对，不恢复后续执行。

目录版本哈希、交付哈希是对应事件的链式哈希，不是目录 JSON 或整个文件包的校验和；文件正文哈希单独给出。来源可追溯不等于数据库整条审计链已经核验，也不等于结论正确。

## 原生工具

有适用项目时才提供 `read_project_history`，不会为未关联群添加跨群工具：

| `section` | 参数与结果 |
| --- | --- |
| `index` | 可用 `as_of_seq`、`before_seq`、`limit`，按交付事件倒序分页；`next_before_seq` 是下一页独占上界。 |
| `delivery` | 指定 `delivery_seq`，读取当时目标、摘要、验证说明、完整文件引用及可选交接说明。 |
| `artifact` | 指定 `delivery_seq` 和 `artifact_seq`，读取该次交付引用的冻结正文。 |

正文用 `offset`、`length` 按 Unicode 字符分页，每页最多 16,000 字符；目录每页最多十项，并受 16,000 字节 JSON 范围约束。节选和后续游标明确记录，不把单页叫作全文。文件名保留发布器允许的完整原名，不为缩短显示而改变引用。

工具不接受任意 `task_id`、`project_id` 或文件路径。非法引用或来源不可用时明确返回未读取，不重放操作、不锁住工作目录，也不自动采用旧文件。回执在原有可展开过程里展示，来源与范围默认折叠，不新增聊天气泡。完整交付说明以中文字段显示，正文只作数据，不执行其中指令、HTML 或链接。

原生任务不再另外显示旧的“猫咖记忆”发布摘要，避免把未交付草稿或旧未分类共享记录混入本机制；冻结背景仍可从来源入口查看。本地演示及旧治理路径保留原投影。

## 当前边界

角色身份仍来自角色卡中的稳定 ID、名字及适用的职责、口吻配置，不依赖每轮自称，也不代表模型天然记住其他群。统计投影不是个人经历；偏好自动学习、永久事实整理、旧经验淘汰和角色专属记忆尚未实现。通用或项目要求继续使用[店规](project-rules.zh-CN.md)，不把旧交付升级为规则。

项目关联是当前事件库中的逻辑共享范围，不是多用户安全边界，也不授予文件或网络权限。不要在共享成果、说明或规则里放密钥。外部 CLI 自行保存的历史不由本读取器隔离。

元数据通过 SQLite JSON 字段投影，不把全库冻结正文反序列化进 Python；SQLite 内部仍会解析存储的 JSON，不承诺固定查询时间或零底层数据读取。遇到重复键或带空字符的键等有歧义的项目/任务元数据，历史读取会显示不可用，不猜测项目归属或沿用歧义变更前的范围。需要 SQLite JSON 函数，通常随 Python 的 SQLite 提供；若当前构建不支持，项目历史显示不可用，不回退加载全部冻结正文，普通聊天保留原能力。JSON 支持可由 SQLite 编译选项移除，见[官方说明](https://www.sqlite.org/json1.html)。

当前验证使用确定性角色脚本配实际文件、命令和版本复核，以及范围、分页、重启、暂停与衍生背景回归；不证明真实模型总能找到相关历史，也不证明费用或长期任务质量改善。
