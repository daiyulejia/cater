# 当前执行能力

Cater 的模型接入与工程执行能力分开提供。仅连接 API 不会自动获得本机权限；绑定预配置工作区后，内置 Anthropic 与兼容 Chat Completions 通道可由当前工作负责人调用文件和命令工具。

| 能力 | 当前状态 |
| --- | --- |
| 中文聊天、点名、任务内语义分流 | 已接入；语义分流需要配置店长模型 |
| 工作项、依赖与阶段/整体验收 | 已接入版本与证据校验；判断质量仍需实际任务验证 |
| 文件成果 | 可阅读、复制、下载正文并自动保存不可变副本；绑定工作区后可修改实际工程文本文件 |
| 打包 | 可下载验收后的正文 ZIP、清单和交接说明；不会自动构建项目安装包 |
| 浏览器检查 | 可选 Playwright 执行器可由原生伙伴检查本群最新发布的静态网页副本，保存操作、断言及具体版本；不是任意浏览器 |
| 本机命令检查 | 显式 `cater verify`，或绑定工作区的 execute 模式调用配置的程序；可对提交源码副本自动运行配置的检查 |
| CLI 接入 | 长驻 NDJSON 外部驱动；实际工具和权限取决于该驱动，随附 Codex 示例固定只读 |
| 官方 Agent 客户端 | 试验性 Qoder CLI CN ACP 通道，复用 Cater 工具与交接/复核；已验证隔离普通工程任务，非通用客户端支持 |
| 本地工程读取、搜索、修改、建目录 | 已有有界 UTF-8 工具，哈希条件写入、按需创建目录及版本回执；尚无通用二进制编辑 |
| 构建、依赖安装、服务和日志管理 | 可显式配置宿主程序并取回日志；尚无成熟安装策略、持久服务管理或任意工程自动构建保证 |
| Git 分支、提交、推送、PR/MR | 尚无 Cater 原生执行流程；检查中的 Git 状态记录不等于版本管理工具 |
| 按需 Skill | 原生伙伴可按角色、工作区和实际工具读取内置或宿主登记的本地 Markdown 指引，索引不自动注入全部正文；不执行脚本或授予权限 |
| MCP | 可选宿主配置的本机 stdio 服务，按角色与工作区按需读取目录和调用；不支持 HTTP/SSE、OAuth 或任意服务自动安装 |
| Android、iOS、桌面、Office 工具链 | 尚未接入对应平台构建、设备测试或文档渲染节点 |
| 文件/网络权限沙箱 | 尚无通用实现；进程组、Windows Job、独立目录不等于权限隔离 |
| 长期群聊、多任务归属 | 有独立后端接口，现有网页仍以一项任务为当前对话 |

任意外部 CLI 可以自行提供更多能力，但必须核实其实际权限与副作用恢复契约，不能沿用纯文本调用的无工具假设。角色名称、职责与店规不授予主机权限。

模型返回的单个 JSON 对象允许完整 Markdown JSON 围栏或一个末尾围栏；内容仍须通过原有字段、来源、版本与权限检查。多对象、前后解释文字、重复字段和不完整 JSON 不会被拼接成可执行建议。解析失败会保留当前任务并显示原因，不代表成员没有做过工作，也不代表任务已完成。

当前恢复能力仍有边界：有副作用的未知结果不能盲重放；阶段检查也不能代替整体行为验收。代码存在和回归通过不能证明复杂长任务始终正确。
