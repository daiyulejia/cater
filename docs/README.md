# Cater 文档

这些文档用于让 Cater 的产品与架构决策保持可审查。

- [组织流程](organization-flow.md)：何时直接派给执行角色、何时内阁分发、何时进入治理。
- [架构复盘](architecture-review.md)：如何检查自身机制是否冗余、成本过高或能力不足。
- [接入复盘](integration-review.md)：如何在把第三方工具包进 driver 边界前检查它。
- [可读成果](artifacts.zh-CN.md)：如何发布正文、标明来源，并在对话中阅读、复制和下载。
- [本机检查](local-verification.zh-CN.md)：显式命令核验的证据与进程运行边界。
- [执行权限设计](execution-permissions.zh-CN.md)：桌面优先、权限预设与沙箱执行边界；目前为未实现的设计提案。
- [持续自驱迭代铁律](autonomy-covenant.md)：如何持续从发起人目标、用户体验和工程证据出发改进项目。

文档应当简短且可操作。若一个机制无法在这里清楚说明，说明它还需要一次设计复盘。
