# 项目与店规

店规用于保留跨任务的工作要求，例如修改公共接口前核对调用方、文稿交付时列出素材来源。目前是**版本化的上下文要求**，不提供文件保护、权限沙箱或自动成果验收。

## 在聊天中使用

聊天输入框上方有“店规”入口。输入一条要求后点击“记为店规”，核对内容和范围再保存；也可以直接打开店规面板编辑。

- **猫咖通用**：适用于当前事件库中的所有项目与任务。
- **当前项目**：适用于明确关联到该项目的任务；后续新任务选择同一项目即可继承。
- **本次任务**：只适用于当前已有任务，不会扩散到其他任务。

新对话可以选择或新建项目。已有未关联任务只能在协作空闲时关联，关联后不能改到另一个项目。项目使用稳定 ID；同名不表示同一个项目。项目关联是逻辑分组，不是文件目录绑定或权限隔离。

普通聊天不会自动变成店规，引用的“禁止……”也不会误建规则。直接从自然语言识别并执行规则管理意图尚未接入。

## 来源与版本

明确保存的用户要求为“已采用”。成员可在实际任务发言中提出带理由的建议，但只记录为“待采用”；打开面板不会自动采用。建议不能自行升级成通用规则或获得工具权限。

规则可修改、采用或停用，历史以新事件保留。并发编辑遇到新版本时，界面保留你的文字并展示最新版，需要核对后再保存。候选的理由是成员报告，不是独立验证结果。

当前每条要求最多 2000 个字符，每条建议理由最多 1000 个字符。每个范围最多采用 32 条、正文合计最多 6000 个字符；候选最多 64 条。超出时拒绝保存，不会悄悄截掉规则后声称全部生效。

## 执行中修改

每次角色调用读取当前适用规则，并在事件中保存实际采用的文字与版本。规则变化后，下一个角色调用会获得新版；失败重试不会继续使用已经过时的规则上下文。

若一轮执行或复核使用了不同版本，或者规则在记录接受决定前发生变化，本轮会记录补证/返工，不将旧规则下的意见作为当前接受结论。原始输出仍保留，下一轮需要重新核对。

已经发出的模型调用或外部工具动作不能因此撤回。目前不会因规则变化自动重跑整个任务，也不会自动撤销之前已作出的决定或重新验收旧成果。成果仍需实际验证。

## 接入约定

Web API 与工作台共用以下入口，遵循同源写入和已有访问令牌检查：

| 入口 | 用途 |
| --- | --- |
| `GET /api/projects` | 读取项目列表 |
| `POST /api/projects` | 以 `name` 新建项目 |
| `POST /api/tasks` | 可选 `project_id`，创建项目内任务 |
| `POST /api/tasks/<id>/project` | 以 `project_id` 关联未绑定且空闲的任务 |
| `GET /api/rules?task_id=<id>` | 读取任务适用的通用、项目和任务规则 |
| `GET /api/rules?project_id=<id>` | 读取项目与通用规则 |
| `POST /api/rules` | 以 `text`、`scope` 和对应的 `project_id` / `task_id` 记录用户要求 |
| `POST /api/rules/<id>` | 以 `revision`、`text`、`status` 更新；过期版本返回 409 |

`scope` 为 `workspace`、`project` 或 `task`；`status` 为 `active`、`candidate` 或 `retired`。修改正文不会改变所属范围。API 的 `enforcement` 为 `guidance_only`；提交其他保护方式会被拒绝。

Driver 的 `context.rule_snapshot` 包含本次规则正文、版本和指纹；`project_id` 仅代表逻辑分组。成员可在协作 JSON 中增加至多两条 `rule_suggestions`，每条包含 `text` 和 `rationale`。运行时根据来源任务限制其范围，不接受模型指定的自动采用状态。

原生消息协作通过[同项目历史背景](project-history.zh-CN.md)按需读取明确同项目的交付；未关联或任务隔离群不自动共享，衍生群只用创建时冻结背景。角色配置持续复用，发言统计和最后一句话不充当个人记忆。旧显式治理路径保留原有同项目成果摘要与近期记录，未关联记录仍共用未分类桶。这不保证外部长驻 driver 自行保存的记忆隔离，也不构成多租户安全边界。历史输出、导出与本地事件库仍可能包含敏感内容，不要把密钥写入店规。

Skill 可以说明如何工作，但不能替代规则的适用性判断、执行权限或验证器。文件保护、有限例外、冲突检查、授权范围内自动采用及基于工具回执的验收尚未实现。
